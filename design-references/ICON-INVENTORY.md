## Icon Style Guide

All custom pixel icons should follow:
- **Canvas**: 16×16 or 32×32 pixel grid (scale 2x for Retina)
- **Palette**: Use ONLY the theme color palette (see DESIGN-SYSTEM.md)
- **Outline**: 1px darker shade of fill color (no black outlines)
- **Style**: Rounded, friendly, low-detail — match the Tamagotchi/lofi aesthetic
- **Format**: PNG with transparency, exported at 1x, 2x, 3x for React Native
- **Naming**: `icon-{name}.png` → `icon-{name}@2x.png` → `icon-{name}@3x.png`
